# Pocket Deck

スマホをWindows PCのショートカットキーボード・タッチパッドにするアプリです。PCにElectronアプリをインストールし、同じWi-Fiのスマホからブラウザーで接続します。スマホへのアプリ導入は不要です。

**Windows x64向けのローカルネットワーク用MVPです。スマホ接続はHTTP・認証なしなので、信頼できる家庭内などのネットワークで使用してください。外部公開・ポート転送には対応していません。**

## ダウンロードと初回設定

1. [Releases](https://github.com/masa-dev-2000/pocket-deck/releases)から `Pocket Deck Setup <version>.exe` をダウンロードします。ソースコードのZIPはインストーラーではありません。
2. インストーラーを実行してインストール先を選びます。Python/Node.jsの追加導入は不要です。
3. Pocket Deckを起動し、PCとスマホを同じWi-Fiにつなぎます。
4. 「スマホを接続」のQRをスマホのカメラで読み取ります。
5. 「配置を編集」でボタンを登録し、PCで入力先のアプリを手前にして操作します。

Windowsのファイアウォール確認が出た場合は、信頼できるプライベートネットワークだけに通信を許可してください。アプリはファイアウォールを自動変更しません。インストーラーは未署名なので発行元不明の警告が表示される場合があります。

## 機能

| 機能 | 内容 |
| --- | --- |
| ショートカット | 検索候補からキーを登録。触れている間押下し、離すと解除。複数指にも対応 |
| 文字列 | ボタン1つで日本語・絵文字・改行などを入力 |
| 配置編集 | 行列の変更・途中への追加削除、長押し移動、複数選択移動、大型ボタン |
| 複数配置・複製 | 配置を作成・複製・切り替え。ボタンも複製可能 |
| 見た目 | 色・アイコン・画像を設定。変更は自動保存 |
| キー配列 | PC風のキー配列画面。下部から配置へ戻れる |
| タッチパッド | 移動、左クリック、2本指スクロール、ダブルタップ保持。配置内にも設置可能 |
| ホイール | スワイプでスクロール。指をずらしたまま保持すると連続スクロール |
| 連続操作 | キー、文字列、待ち時間、Chromeプロフィール切り替えを順番に実行 |
| Chrome連携 | 指定プロフィールのウィンドウへ移動。[設定手順](docs/chrome-profiles.md) |

操作画面全体はスクロールさせず、表示領域へ配置を収めます。キー候補など一部の一覧には内部スクロールがあります。行列を増やすほどボタンが小さくなるので、必要に応じて配置を分けてください。

**既知の問題：ダブルタップ保持ドラッグは、ファイル移動・ウィンドウのサイズ変更でクリックとして扱われる報告があります。修正は未収録です。** 詳細は[利用ガイド](docs/usage.md)をご覧ください。

## 終了・更新・データ

- ウィンドウの「×」は通知領域へ格納します。完全終了は「アプリを終了」または通知領域メニューから行います。
- 登録内容は `%APPDATA%\Pocket Deck\data` に保存します。インストール先とは別です。
- 更新は完全終了後、最新版インストーラーを実行します。自動更新はありません。
- 配布物に開発者の登録内容・画像・トークンは含めません。初回はサンプル配置です。
- アンインストールでも登録データは自動削除しません。[バックアップ手順](docs/usage.md#バックアップと更新)を参照してください。
