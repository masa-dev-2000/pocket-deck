# Pocket Deck

スマホをWindows／Ubuntu PCのショートカットキーボード・タッチパッドにするアプリです。PCにElectronアプリをインストールし、同じWi-Fiのスマホからブラウザーで接続します。スマホへのアプリ導入は不要です。

**Windows／Ubuntu x64向けのローカルネットワーク用MVPです。スマホ接続はHTTP・認証なしなので、信頼できる家庭内などのネットワークで使用してください。外部公開・ポート転送には対応していません。**

Ubuntu対応は1.1.0以降です。[Ubuntuの導入案内](docs/ubuntu.md)と[実装・検証記録](docs/linux-support.md)を参照してください。X11／Waylandの選択はアプリが検出します。

macOS 13以降のApple Silicon／Intel向け試験コードは開発中です。正式な署名・公証、実機での入力許可と操作確認はまだ完了していません。[Mac試験版の案内](docs/macos.md)を参照してください。Mac向けインストーラーはまだ公開していません。

**1.2.0-beta.1（試験公開）**では、スマホごとのカーソル・スクロール感度、入力許可がない操作の停止、Ubuntuの接続診断・限定LAN許可を追加しました。Windows／Ubuntu x64の配布物は[GitHubのプレリリース](https://github.com/masa-dev-2000/pocket-deck/releases/tag/v1.2.0-beta.1)から取得できます。npmでこの版を使う場合は`@masadev/pocket-deck@beta`を指定してください。通常の`latest`は1.1.0です。

## ダウンロードと初回設定

1. [Releases](https://github.com/masa-dev-2000/pocket-deck/releases)から `Pocket-Deck-Setup-<version>.exe` をダウンロードします。ソースコードのZIPはインストーラーではありません。
2. インストーラーを実行してインストール先を選びます。Python/Node.jsの追加導入は不要です。
3. Pocket Deckを起動し、PCとスマホを同じWi-Fiにつなぎます。
4. 「スマホを接続」のQRをスマホのカメラで読み取ります。
5. 「配置を編集」でボタンを登録し、PCで入力先のアプリを手前にして操作します。

Windowsのファイアウォール確認が出た場合は、信頼できるプライベートネットワークだけに通信を許可してください。アプリはファイアウォールを自動変更しません。インストーラーは未署名なので発行元不明の警告が表示される場合があります。

Ubuntuは`Pocket-Deck-<version>-amd64.deb`を`sudo apt install ./<ファイル名>`で導入します。追加のPython／Node.jsは不要です。OSの入力許可はPCアプリから案内します。Ubuntu向けnpm版は1.1.0以降です。

Node.js 22.12以上を使っている人は、次のコマンドでPCアプリの自動導入と初回起動まで進められます（1.0.4以降）。

```powershell
npm install -g @masadev/pocket-deck
```

PCアプリ本体はGitHub Releasesから取得・検証して、現在のWindowsユーザー用に導入します。npmのインストールスクリプトが実行可能であることが必要です。既存アプリは完全終了してから実行してください。ローカルの`npm install`では自動導入しません。[npmの配布手順](docs/npm.md)を参照してください。

Ubuntuでは通常ユーザーで`npm install -g --prefix "$HOME/.local" --foreground-scripts @masadev/pocket-deck`を実行し、表示されるOSの認証を完了します。npm全体をsudoで実行しません。

## 機能

| 機能 | 内容 |
| --- | --- |
| ショートカット | 検索候補からキーを登録。触れている間押下し、離すと解除。複数指にも対応 |
| 文字列 | ボタン1つで日本語・絵文字・改行などを入力 |
| 配置編集 | 行列の変更・途中への追加削除、長押し移動、複数選択移動、大型ボタン |
| 複数ページ・複製 | 上部タブでページを切り替え。追加・複製・並べ替えと、キー配列／パッドのテンプレートに対応 |
| まとめボタン | 複数のボタンを一つにまとめ、候補からショートカット・文字列・連続操作などを実行 |
| 見た目 | 色・アイコン・画像を設定。変更は自動保存 |
| キー配列 | 編集可能なページテンプレートとして追加可能 |
| タッチパッド | 移動、左クリック、2本指スクロール、ダブルタップ保持。配置内にも設置可能 |
| ホイール | スワイプでスクロール。指をずらしたまま保持すると連続スクロール |
| 操作感（beta） | スマホのブラウザごとにカーソルとスクロールの速度を調整 |
| 入力許可（beta） | PCで許可されていないキー・マウス操作を表示・停止 |
| Ubuntu接続診断（beta） | LANを選び、UFWを使う場合は指定LANからの接続だけを許可・解除 |
| 連続操作 | キー、文字列、左クリック、待ち時間、Chromeプロフィール切り替えを順番に実行 |
| Chrome連携 | 指定プロフィールのウィンドウへ移動。[設定手順](docs/chrome-profiles.md) |

操作画面全体はスクロールさせず、表示領域へ配置を収めます。キー候補など一部の一覧には内部スクロールがあります。行列を増やすほどボタンが小さくなるので、必要に応じて配置を分けてください。

**既知の問題：ダブルタップ保持ドラッグは、ファイル移動・ウィンドウのサイズ変更でクリックとして扱われる報告があります。修正は未収録です。** 詳細は[利用ガイド](docs/usage.md)をご覧ください。

## 終了・更新・データ

- ウィンドウの「×」は通知領域へ格納します。完全終了は「アプリを終了」または通知領域メニューから行います。
- 登録内容は `%APPDATA%\Pocket Deck\data` に保存します。インストール先とは別です。
- Ubuntuでは通常`~/.config/Pocket Deck/data`です（`XDG_CONFIG_HOME`を指定した場合はその配下）。
- 1.0.4以降は起動時に新版を確認します。「更新する」を選ぶと取得・更新・再起動します。メニューからも確認できます。1.0.3からの初回更新はnpmまたは新版インストーラーで行います。
- 配布物に開発者の登録内容・画像・トークンは含めません。初回はサンプル配置です。
- アンインストールでも登録データは自動削除しません。[バックアップ手順](docs/usage.md#バックアップと更新)を参照してください。
