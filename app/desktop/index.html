Chrome連携

仕事用・個人用などのChromeへ、ボタンひとつで切り替え。

このPCはWayland環境です。Chrome側の画面制御方式によっては、接続中でも別のウィンドウへの切り替えが拒否されます。ChromeをX11モードで起動すると利用できる場合があります。Pocket DeckがChromeを自動で終了することはありません。

アプリの更新後や「準備を確認・修復」の後は、各プロフィールの chrome://extensions でPocket Deck拡張の再読み込みボタンを押してください。Chromeの再起動だけでは変更が反映されない場合があります。

1. PC側を準備

状態を確認しています…

このユーザーの連携設定だけを登録します。拡張IDの入力やコマンド操作は不要です。

2. 各Chromeに拡張を追加

  1. 使いたいプロフィールのChromeで chrome://extensions を開く。
  2. 「デベロッパーモード」をオンにする。
  3. 「パッケージ化されていない拡張機能を読み込む」で下のフォルダーを選ぶ。

  4. Chromeの拡張アイコンから「Pocket Deck Profile Bridge」を開き、「仕事用」などの呼び名を入力して「登録・再接続」を押す。

切り替えたいプロフィールごとに、この手順を行います。旧拡張から移行する場合は、新しい拡張で登録後、ボタンの対象を選び直してください。

3. 接続を確認して割り当て

    ボタン編集で「入力種類 → Chromeプロフィール」から対象を選びます。閉じたChromeは起動せず、タブも変更しません。
