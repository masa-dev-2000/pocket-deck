# 連続操作の編集

「配置を編集」で連続操作ボタンを選ぶと、手順の編集画面が直接開きます。
名前、キー、文字列、待ち時間の変更は自動保存です。「保存済み」を確認してから画面を閉じてください。

- PCでは左に手順一覧、右に選択した手順の編集欄を表示します。
- スマホでは選択した行に編集欄を展開します。もう一度選ぶと閉じます。
- 順番は左端のハンドルをドラッグして変更できます。「⋯」から上／下へ移動、複製、削除もできます。
- 待ち時間は秒で入力します。0.5秒のプリセットや0.001秒単位の入力に対応します。保存データの単位は従来どおりミリ秒です。
- 「＋ 手順」「既存ボタンから」「テンプレート」は下部にあります。手順は最大50個です。
- 「配置へ戻る」で配置一覧へ戻ります。色・画像・キーの大きさは「ボタン設定」で変更します。

画面全体はスクロールせず、長い手順一覧や編集欄だけをスクロールできます。編集画面から操作を実行する機能はありません。
未入力や範囲外の値は保存されず、エラーを表示します。途中の入力は端末内に保持されます。

マウスホイールボタンには「ホイールの上下方向：標準／逆向き」があります。ボタンごとの設定で、スワイプと保持スクロールの上下方向を反転します。横方向は変わりません。
