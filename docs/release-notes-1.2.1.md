# Pocket Deck 1.2.1

WindowsでNum Lock、Caps Lock、Scroll Lock、Insert、Print Screen、Pause、アプリケーションメニュー、テンキー、主要な記号キーをショートカットと連続操作に登録できます。キーの保存値を表示名から分離し、検索と再編集に対応しました。

Windowsの実機で `.,/` の入力とNum Lockの切り替えを確認しました。Ubuntu・macOSの入力対応は変更していません。両OSでWindows専用キーを含む設定を読み込んでも保持し、実行時にはエラーを返します。

macOS版は引き続き試験版で、Developer ID署名・公証と実機での入力確認は未完了です。
