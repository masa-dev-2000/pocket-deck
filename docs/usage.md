# 利用ガイド

## 対応環境・接続

Windows x64用インストーラーを用意しています。Windows ARM64、macOS、Linux向けは未対応です。スマホは同じLANのブラウザーで接続します。iPhone SE（第3世代）で一部の表示・操作を確認していますが、全端末の動作保証ではありません。

PCはTCP 8765を使用します。ゲストWi-Fi、端末間通信の遮断、VPN、ファイアウォールにより同じWi-Fiでも接続できない場合があります。PCのIPが変わったときはQRを読み直してください。

スマホ接続はHTTP・認証なしです。同じネットワークからアクセスできる端末はPC入力や編集を実行できるため、信頼できるネットワークでのみ使用してください。外部公開、ルーターのポート転送、公共Wi-Fiは想定していません。

## 配置・登録

「配置を編集」で枠を選び、入力種類・表示名・内容・色を設定します。キーは検索候補から選択します。入力停止から約600ms後、入力欄を離れたとき、選択確定時に自動保存します。日本語変換途中や必須項目が空の状態は保存しません。保存状態を確認してください。

列数1〜12、行数1〜200、各配置最大200ボタン、配置最大20です。横幅・高さを変えると複数マスのボタンを作れます。行列の途中への追加／削除、複数選択移動も編集画面で操作します。収まらない縮小は適用せず、既存配置を保ちます。

長押しドラッグで移動します。ボタン・配置の複製は独立したコピーです。色、アイコン、PNG/JPEG/WebP画像に対応します。画像は5MB・2500万画素以内、保存時に最大512pxのPNGへ変換します。

## 入力種類

- **ショートカット**：触れると押下、離すと解除。最大8キー。英数字、F1〜F24、修飾キー、矢印などに対応。日本語固有キーなどは未対応です。
- **文字列**：タップで全文を1回入力。最大1,000文字。日本語・絵文字・改行・タブに対応し、クリップボードは置き換えません。
- **画面切り替え**：キー配列、パッド、別配置へ移動。キー配列の下部から配置へ戻れます。
- **タッチパッド**：配置内にも複数マスで設置可能。1本指移動、タップで左クリック、2本指で縦横スクロール。右クリックは未対応です。
- **ホイール**：スワイプでスクロール。保持方式では触れ始めた位置からの移動量に応じて、指を置く間スクロールを続けます。
- **連続操作**：キー・文字列・待機・押下／解除・Chromeプロフィールを順番に実行。最大50手順、待機1回10秒、全体60秒です。
- **Chromeプロフィール**：[設定ガイド](chrome-profiles.md)に従い準備。最後に使った通常ウィンドウへ移動し、タブは変更しません。

Windows検索でアプリを開く連続操作には、検索画面の準備を待つ時間を入れます。送信完了はアプリ起動成功まで保証しません。実行中はほかの入力を拒否し、停止・画面切り替え・通信断などで中断します。

PCの前面アプリに入力します。管理者権限のアプリや一部ゲームには入力できません。一律に管理者として起動することは推奨しません。

## 解除・終了

「全キー解除」は保持キー・マウスボタン・連続操作を停止します。通常は指を離すと解除し、画面移動、バックグラウンド移行、約2秒の通信断でも解除します。

PCウィンドウの「×」は通知領域へ格納します。完全終了はアプリ内または通知領域メニューから行います。アプリ自身が起動したサーバーは終了時に停止します。既存サーバーを利用した場合は、そのサーバーを停止しません。

## バックアップと更新

`%APPDATA%\Pocket Deck\data` に `config.json` と画像の `assets`、Chromeトークンを保存します。トークンは公開しないでください。

1. 接続を停止し、アプリを完全終了します。
2. データフォルダを別の場所へコピーします。
3. 新版インストーラーを実行します。
4. アプリを起動し、配置・接続・入力を確認します。

更新・アンインストールで登録データは自動削除しません。復元時も先にアプリと関連サーバーを終了し、現状をバックアップしてから戻します。新しい設定形式を古いアプリで開かないでください。

## 既知の問題と確認範囲

- ダブルタップ保持ドラッグはファイル移動・ウィンドウサイズ変更でクリックになる報告があります。クリック送信方式の修正は未収録です。
- iPhone SE実機で画面の収まり、キー保持、配置移動、2本指スクロールなどを確認済みですが、全機能・全端末の検証ではありません。
- Chrome連携は模擬APIと同梱ホストを自動検証。実拡張を導入した環境でも確認してください。
- 別PCでの新規導入・全機能の実機確認は未実施。インストーラー未署名、自動更新なしです。
- 同時編集は更新番号で競合を検出。「保存失敗」は保存状態から確認・再試行できます。
