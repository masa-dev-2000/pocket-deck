# Pocket Deck 1.2.3

- まとめボタン内の項目を編集・追加・削除した後、候補一覧に戻るように修正しました。
- まとめボタン内の連続操作にも「候補一覧へ戻る」を表示し、編集画面の階層を保ちます。
- 空のまとめボタンを作成し、後から候補を追加できます。
- 編集画面のメニューに「PCの便利操作」を追加。PCに登録した操作の名前・キー・説明を一覧表示します。
- 既存の配置・登録データを保持します。

## PCの便利操作の台帳

データフォルダーの `local-actions.json` に配列で登録します。未作成の場合は空の一覧になります。
Windowsは `%APPDATA%\Pocket Deck\data`、Linuxは `~/.config/Pocket Deck/data` が既定です。

```json
[
  {
    "label": "最新スクショをコピー",
    "keys": "F14",
    "description": "最新のスクリーンショットをコピーするPC側の処理を呼び出します。"
  }
]
```

この台帳は表示用です。キーとスクリプトを結び付ける処理はPC側で別途用意します。
任意のスクリプトを実行するAPIは追加していません。キー送信には既存のショートカットボタンを使います。
個人用スクリプト・設定・画像は配布物へ含めません。
