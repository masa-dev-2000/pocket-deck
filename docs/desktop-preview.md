# PCでスマホの配置をプレビューする

PCアプリの「配置を編集」は、スマホの画面サイズで表示します。
上部の「スマホ」でiPhone SE（第3世代）、iPhone 16、Androidの代表的なサイズ、カスタムサイズを選べます。
「横向きにする／縦向きにする」で向きを切り替えられます。

カスタムの幅・高さは240〜1440の整数です。端末の物理的な解像度ではなく、Web画面の表示領域のサイズを入力します。
プリセットはiPhone SE 375×667、iPhone 16 393×852、Android標準360×800、大画面412×915です。Androidの項目は特定機種の保証ではありません。

画面のレイアウトは指定サイズのまま、PCウィンドウに収まるよう外側だけ縮小します。
プレビュー内での変更は実際の配置に自動保存され、スマホにも反映されます。
選択した端末、カスタムの幅・高さ、向きはこのPCに保存されます。配置データのサイズ・行列数は端末の選択によって変わりません。
「スマホを接続」のQR表示はスマホ枠に縮小しません。

このプレビューは表示サイズを確認する機能です。Safariの上下バー、OSの文字サイズ、画面の切り欠き、ソフトウェアキーボードは再現しません。実際のスマホでの確認も必要です。

デスクトップアプリの左下には、起動中のアプリ自身から取得したバージョンを表示します。接続サーバーが停止していても表示します。

参考：Appleの[iPhone SE仕様](https://support.apple.com/en-au/111866)、[iPhone 16仕様](https://www.apple.com/iphone-16/specs/)。物理解像度とWeb画面の表示サイズは別の単位です。
